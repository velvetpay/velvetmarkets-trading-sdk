# API Overview

The commercial SDK exposes structured interfaces for:

- market research
- signal generation
- risk calculation
- position management
- broker connectivity
- decision auditing
- licence validation

Typical integrations submit market and application context and receive structured trading-intelligence responses.

Detailed function signatures, schemas, implementation modules and proprietary algorithms are provided only with the licensed SDK package.

Public documentation intentionally does not reproduce the internal SDK source or trading methodology.
