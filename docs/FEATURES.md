# Features

VelvetMarkets Trading SDK is designed as modular trading infrastructure for applications that require research, signal, risk and execution capabilities.

## Research Intelligence

- Multi-timeframe market assessment
- Opportunity qualification
- Asset ranking
- Market condition evaluation

## Trading Intelligence

- BUY / SELL / NO TRADE decisions
- Strategy and research agreement checks
- Confidence assessment
- Structured reasons for decisions

## Risk Infrastructure

- Position sizing
- Risk limits
- Stop-loss management
- Progressive trailing protection
- Risk/reward evaluation

## Portfolio Infrastructure

- Spot-position normalisation
- Portfolio reconciliation
- Broker-aware position utilities

## Integration

- Broker-neutral architecture
- Coinbase Advanced support
- REST integration
- Audit and decision records

Implementation algorithms and proprietary source code are supplied only through licensed SDK distribution.
