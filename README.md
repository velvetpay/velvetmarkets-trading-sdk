# VelvetMarkets Trading SDK

Commercial trading intelligence infrastructure from Velvet Technologies.

VelvetMarkets Trading SDK provides developers with infrastructure for market research, trading-signal qualification, risk management, portfolio intelligence, audit logging and broker integration.

## Capabilities

- Multi-timeframe market research
- BUY / SELL / NO TRADE qualification
- Opportunity ranking and confidence assessment
- Position sizing and risk controls
- Stop-loss and progressive trailing protection
- Portfolio and position utilities
- Broker-neutral integration architecture
- Coinbase Advanced integration support
- Decision and audit logging
- REST integration support
- Application-bound commercial licensing
- Safe sandbox evaluation

## Commercial SDK

This repository is a product showcase and documentation repository.

The proprietary VelvetMarkets Trading SDK implementation is not published in this repository.

Licensed SDK packages are supplied separately to authorised customers.

## Safety

VelvetMarkets Trading SDK is developer infrastructure and does not provide investment advice or guarantee trading performance or profits.

Broker credentials and customer secrets remain under the integrating developer's control.
